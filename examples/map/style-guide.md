# Style guide

How the shop writes for people: docs, the README, labels, buttons and error messages.

- Plain and friendly. Explain it the way you would to a customer at the till.
- Short sentences, one idea each. Start with what the reader can do.
- British spelling: colour, organise, cancelled.
- Buttons say what happens: "Pay £24.00", not "Submit".
- An error message says what went wrong and what to do next: "That code has expired. Try another, or carry on without one."
- No exclamation marks, and no jokes in errors.
- Docs start with what the thing is for, then how to use it. Address the reader as "you".
