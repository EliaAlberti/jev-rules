---
description: Building or changing a user interface component, page, form, button, modal or anything a user sees or clicks.
---
Every interface change is usable without a mouse and without sight.

- Every control has a visible label or an aria-label, and is reachable by keyboard.
- Colour contrast is at least 4.5 to 1. Never signal state with colour alone.
- Modals trap focus and return it on close.
